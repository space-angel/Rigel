쓰는 법 시작하기 처음 열 때
macOS · Windows · 내 Claude 구독으로

뭐부터 할지 모를 때,
첫 행동부터.

떠오른 일을 적으면 바로 시작할 수 있는 작은 행동 하나로 바꿔 줘요. 메뉴바에서 오늘 할 일만 조용히 보여 주는 할 일 앱이에요.

다운로드 최신 버전
Mac (Apple Silicon) Mac (Intel) Windows 지난 버전

이렇게 써요

적는 순간부터 실제로 시작하기까지 거리를 줄이는 데만 집중했어요.

어디서든 단축키로 적기

어느 앱을 쓰고 있든 단축키 하나로 적어요. 짧으면 바로 오늘 할 일로, 길면 Claude가 할 일 여러 개로 나눠 줘요. ‘금요일까지’, ‘내일’ 같은 날짜 말도 알아들어요.

막막한 일은 첫 행동으로

‘면접 준비’처럼 큰 일은 지금 바로 할 수 있는 작은 행동 하나로 바꿔 줘요. 맨 위 할 일은 묻기 전에 미리 찾아 두어서, 누르자마자 보여요.

내 자료를 보고 만들기

Figma 바로가기, 끝낸 할 일, 그리고 연결한 Notion·Linear·Figma를 참고해 내 상황에 맞는 첫 행동을 만들어요. 어떤 자료를 참고했는지도 함께 보여 줘요.

시작하기

3분이면 돼요.

1

Claude Code 준비

Claude Code를 설치하고, 터미널에서 claude를 실행해 로그인해요. Pro·Max·Team 구독이나 API 키면 돼요.

2

받아서 열기

위에서 받은 파일로 설치해요. 처음 열면 시작하기 화면이 Claude Code를 찾았는지, 로그인했는지 확인해 줘요.

3

단축키로 적기

맥은 ⌥ Space, 윈도우는 Alt+Shift+Space. 떠오른 일을 적고 Enter를 누르면 끝이에요.

처음 열 때 경고가 떠요

아직 서명하지 않은 앱이라서 그래요. 한 번만 허용하면 다음부터는 그냥 열려요.

Mac

  1. 받은 dmg를 열고 todoBAN을 응용 프로그램 폴더로 옮겨요
  2. todoBAN을 열면 확인할 수 없다는 창이 떠요. 완료를 눌러 닫아요
  3. 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 그래도 열기를 눌러요
  4. 다시 열고 열기를 누르면 메뉴바에 아이콘이 생겨요

Windows

  1. 받은 setup.exe를 실행해요
  2. ‘Windows의 PC 보호’ 창이 뜨면 추가 정보를 눌러요
  3. 실행을 누르고 설치를 마쳐요
  4. 작업 표시줄 오른쪽 트레이에 아이콘이 생겨요. 안 보이면 ^를 눌러 찾아요

내 정보는 내 컴퓨터에

todoBAN은 내 Claude Code를 실행만 해요. 계정 정보는 직접 다루지 않아요.

  • 할 일과 설정은 내 컴퓨터에만 저장해요
  • Claude에는 할 일 이름과 고른 자료의 이름만 보내요
  • 파일 내용·링크·파일 위치는 보내지 않아요
  • Notion·Linear·Figma는 읽기만 해요
  • 새 버전은 앱이 알아서 확인해요(윈도우는 자동 설치)
  • 짧은 할 일은 Claude 없이도 적을 수 있어요
