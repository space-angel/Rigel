02

받아서 열기

Mac (Apple Silicon) · Mac (Intel) · Windows

03

단축키로 적기

떠오른 일을 적고 Enter. 시작하기 화면이 Claude Code를 찾았는지, 로그인했는지 먼저 확인해 줘요.

처음 열 때 경고가 떠요 서명 전이라 그래요. 한 번만 허용하면 돼요

Mac

  1. dmg를 열고 앱을 응용 프로그램 폴더로 옮겨요
  2. 앱을 열면 뜨는 창에서 완료를 눌러요
  3. 시스템 설정 → 개인정보 보호 및 보안 맨 아래 그래도 열기
  4. 다시 열고 열기를 누르면 메뉴바에 아이콘이 생겨요

Windows

  1. setup.exe를 실행해요
  2. ‘Windows의 PC 보호’ 창에서 추가 정보
  3. 실행을 누르고 설치를 마쳐요
  4. 작업 표시줄 오른쪽 트레이에 아이콘이 생겨요

내 컴퓨터에만

할 일과 설정은 내 컴퓨터에만 저장해요. Claude에는 이름만 보내고, 파일 내용과 링크는 보내지 않아요.

내 Claude로

Rigel은 내 Claude Code를 실행만 해요. 계정 정보는 직접 다루지 않아요.

알아서 새 버전

새 버전이 나오면 앱이 알려 줘요. 윈도우는 다시 켤 때 자동으로 바뀌어요.
